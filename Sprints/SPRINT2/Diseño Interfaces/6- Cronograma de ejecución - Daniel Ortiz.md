## Planificación de tareas del sprint

El sprint se divide en varias fases para organizar el trabajo, distribuir el tiempo disponible y comprobar que se cumplen los objetivos establecidos. Las tareas se gestionarán mediante el tablero Kanban de GitHub Projects, donde se podrá consultar su estado y progreso.

### 1. División del sprint en fases

| Fase | Tareas | Tiempo estimado |
| --- | --- | --- |
| 1. Análisis | Revisar los requisitos de las interfaces y la estructura de las páginas. |  h |
| 2. Diseño y planificación | Definir la estructura HTML y los componentes visuales que se utilizarán. |  h |
| 3. Maquetación HTML5 | Crear las páginas de inicio de sesión, registro y panel de control. |  h |
| 4. Desarrollo CSS | Aplicar estilos, organizar las clases mediante BEM y adaptar los diseños. |  h |
| 5. Pruebas y validación | Comprobar la estructura de las páginas, los enlaces y la visualización de los componentes. |  h |
| 6. Ajustes finales | Corregir errores, mejorar detalles visuales y actualizar la documentación. |  h |
| **Total** | | ** h** |
