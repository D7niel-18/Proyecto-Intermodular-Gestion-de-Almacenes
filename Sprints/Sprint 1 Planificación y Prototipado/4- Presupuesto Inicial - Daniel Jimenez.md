# Sprint 1 - Presupuesto básico

## 4. Presupuesto básico

### Recursos humanos

El principal recurso del proyecto es el tiempo dedicado por los integrantes del equipo. El proyecto está formado por **3 miembros**, estimando aproximadamente **200 horas de trabajo por persona** durante el desarrollo. Estas horas incluyen tareas de análisis, planificación, diseño, programación, pruebas, documentación y corrección de errores.

Para realizar una estimación más próxima al valor de un desarrollo profesional, se establece un coste de referencia de **18 € por hora de trabajo**.

Somos 3 miembros en el equipo:

* **Daniel JR:** 200 h × 18 €/h = **3.600 €**
* **Pepe GC:** 200 h × 18 €/h = **3.600 €**
* **Daniel O:** 200 h × 18 €/h = **3.600 €**

Por tanto:

* **Horas totales:** 600 h
* **Coste estimado por hora:** 18 €
* **Valor estimado del trabajo:** **10.800 €**

Esta cantidad representa el valor económico estimado de las horas de trabajo del equipo y **no supone un gasto económico real**, ya que se trata de un proyecto académico.

### Herramientas o licencias necesarias

Se utilizarán principalmente herramientas gratuitas o de código abierto para reducir los costes directos del proyecto:

* **Visual Studio Code:** editor de código gratuito.
* **Node.js y Express:** tecnologías gratuitas y de código abierto para el backend.
* **Angular:** framework gratuito y de código abierto para el frontend.
* **MySQL:** sistema de gestión de bases de datos disponible en una edición gratuita.
* **Git y GitHub:** utilizados para el control de versiones y el trabajo colaborativo.
* **Figma:** utilizado para el diseño y prototipado de la interfaz mediante las funcionalidades disponibles en su plan gratuito.

**Coste estimado de licencias: 0 €**, siempre que se utilicen las versiones y planes gratuitos.

### Otros gastos

También se han considerado posibles gastos relacionados con el desarrollo y una futura puesta en producción:

* **Pruebas con usuarios:** 0 €, realizadas con compañeros, profesores o usuarios cercanos.
* **Imágenes e iconos:** 0 €, utilizando recursos gratuitos o librerías de iconos con licencias que permitan su uso.
* **Dominio:** aproximadamente **15 €/año** en caso de publicar la aplicación.
* **Hosting o servidor:** aproximadamente **300 €/año**, dependiendo del proveedor y de los recursos necesarios.
* **Copias de seguridad y almacenamiento:** aproximadamente **120 €/año**.
* **Certificado SSL:** 0 €, utilizando las opciones gratuitas disponibles.

Los costes de dominio, alojamiento y almacenamiento son **orientativos** y no se consideran gastos directos durante la fase académica, ya que el desarrollo se realizará principalmente en un entorno local.
