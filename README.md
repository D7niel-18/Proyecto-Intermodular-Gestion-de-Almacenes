# Proyecto-Intermodular-Gestion-de-Almacenes
Este proyecto consiste en el desarrollo de una aplicación web destinada a facilitar y optimizar la gestión del stock de las empresas. La aplicación permitirá organizar y controlar el inventario de forma eficiente, clasificando los productos por categorías y proporcionando una visión centralizada del stock disponible.

Además, estará diseñada para empresas que dispongan de varios almacenes o incluso que una persona pueda tener varias empresas, permitiendo gestionar toda la información desde un único panel de administración. De esta manera, se busca simplificar el control del inventario, mejorar la organización y facilitar la toma de decisiones relacionadas con la gestión del stock.
